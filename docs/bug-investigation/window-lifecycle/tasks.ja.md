# 実装計画

1. 既存の未コミット変更を保存し、ウィンドウ管理と言語処理を調査する。
2. 回帰テストを追加し、修正前の失敗を記録する。
3. ネイティブの閉じ方・再利用と画面サイズを統一し、デリゲート寿命を維持する。
4. テストとリリースビルドを実行し、修正差分をレビューする。
5. インストール済みアプリをバックアップし、更新後に英日の再表示・開閉を確認する。
6. 証拠、5 Whys、Fishbone、Timeline、再発防止を英語・日本語で記録する。

7. 設定項目を整理し、4タブを両言語で確認する。

8. カテゴリ編集の表示を修正し、初回の入力済み表示とキャンセル後の再表示を確認する。

9. 管理画面のカテゴリ追加導線を設け、データを書き込まず表示とキャンセルを確認する。
