# ウィンドウ管理の要件

報告症状：英日対応の追加後、設定・管理画面の開閉で空白または黒いウィンドウが時々残る。

- 既存の英語・日本語対応とユーザーデータを維持する。
- 設定・統計の管理クラスは、それぞれ再利用可能なウィンドウを最大1つ所有する。
- 画面内の閉じる、Escape、タイトルバーの×で同じウィンドウを閉じ、再表示すると内容を表示する。
- 言語切り替えで内容とタイトルを更新し、追加ウィンドウを作らない。
- ネイティブ画面サイズとSwiftUIのルートサイズを一致させる。
- 繰り返し開閉の回帰テスト、リリースビルド、インストール済みアプリの操作で検証する。

- 設定ヘッダー・閉じるを常時表示し、タイマー・アプリ・カレンダー・カテゴリのタブに整理する。

- カテゴリ編集は初回から対象の名前・絵文字が入力された編集画面を開く。

- 管理画面のカテゴリタブから直接カテゴリを追加できる。
