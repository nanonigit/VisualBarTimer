# VisualBarTimer (ビジュアルバータイマー for macOS)

キングジム「ビジュアルバータイマー (VBT10)」の使いやすさと視認性を再現した、macOSネイティブのフローティングバータイマーアプリです。

## 特徴

1. **バー表示**:
   * **横向き**: 右から左に向かって目盛が減少（直感的な残り時間把握）
   * **縦向き**: 上から下に向かって目盛が減少
   * **カラー/白黒テーマ**:
     * カラー: 緑（50%超）→ 黄（20〜50%）→ 赤（20%以下）
     * 白黒: ハイコントラストなモノトーン表示
2. **ウィンドウ & 操作性**:
   * **フローティング & 最前面固定**: ピン留めボタンで常時最前面に固定可能
   * **サイズ切替**: 小 (Small) / 中 (Medium) / 大 (Large)
   * **直感セット**: バー上を直接クリックまたはドラッグして時間をセット可能
   * **クイックプリセット**: 3分, 5分, 10分, 15分, 25分, 30分, 60分
3. **モード & 通知**:
   * **カウントダウン / カウントアップ / ポモドーロ**
   * **終了時**: システムサウンド ＋ バーの点滅フラッシュ ＋ macOS通知

## 起動方法

```bash
cd /Users/naoki/.gemini/antigravity/scratch/VisualBarTimer

```

cd /Users/naoki/.gemini/antigravity/scratch/VisualBarTimer
